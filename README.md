The repository has been created to include a python script whose purpose is to provide an example of working fluid selection in a binary ORC power cycle operating with a typical medium-enthalpy geothermal source. The script is developed monolithically in a single file given the short lenght.

The algorithm computes a condensing Rankine Cycle with no superheating for each of the fluids that are present in Coolprop 8.0.0. at optimized maximum cycle pressure, limited by the minimum temperature difference inside the evaporator. The data and hypothesis can be deduced from the script.

The script is part of a bachelor's thesis in Energy Engineering with title "ORC systems for the exploitation of medium‑to‑low enthalpy geothermal sources"
